# Music Streaming Application

## Overview
This project is a complete music streaming application built with modern technologies.

## Features
- Modern dark theme with purple/blue neon accents.
- Glassmorphism design elements.
- Full music search functionality.
- Interactive music player with play, pause, next, previous, and volume controls.
- Create and manage playlists.
- Mark favorite songs.
- Music recommendations from LastFM API.
- Trending songs section.
- Recently played history.
- Fully responsive design for mobile, tablet, and desktop.
- Context API for state management.
- RESTful backend API.
- LocalStorage for persistence.
- Smooth animations and transitions.

## Getting Started
### Prerequisites
- Node.js
- npm or yarn

### Installation
1. Clone the repository
2. Install dependencies for both frontend and backend.

### Running the App
1. Start the backend server
2. Start the frontend development server
